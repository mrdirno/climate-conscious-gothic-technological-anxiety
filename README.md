## Entry Points for Contributors

**Start anywhere. Fork freely. No permission needed.**

### Story Entry Points

- Write a journal entry from Marten the Carrier's perspective, detailing his conflicting loyalties between the Council's mandates and the homesteaders he serves.
- Describe a day in the life of a technician inside the Spire, monitoring the Harmony Node data streams and encountering an anomaly from Elara's land.
- Create a 'found document'—a decaying Council memo or a fragment of Silas's old engineering notes—that reveals a hidden truth about the Great Unraveling.
- Write a scene where the Old House itself seems to react to the Harmony Node, with strange noises in the pipes or shifts in the biolume glow, from the perspective of a minor object (e.g., the root tea kettle, a specific floorboard).

### Technical Entry Points

- Design a schematic for a 'legacy system' monitor like those built by Silas, using salvaged parts and emphasizing manual feedback loops vs. automated data streams.
- Propose a data visualization project that maps the 'emotional weather' of the homestead—combining environmental sensor data with inferred character stress from the text—as an alternative to the Spire's cold metrics.
